# 新版点赞功能部署与迁移

新版点赞不再把微信 `OPENID` 保存到公开的 `posts.likers` 数组。每一次点赞会在私有 `postLikes` 集合中保存唯一记录，并通过事务同步帖子点赞数。

## 1. 创建集合

在当前云环境创建 `postLikes` 集合，客户端权限设置为“所有用户不可读写”。该集合只能由云函数访问。

## 2. 部署云函数

依次上传并部署：

1. `likePost`：选择“云端安装依赖”。
2. `adminCommunity`：选择“云端安装依赖”。
3. `ensureUser`：协议同意记录也在本次更新中，需一并重新部署。

## 3. 迁移旧点赞

部署完成后，使用管理员账号进入“我的 → 管理入口 → 帖子管理”，点击“迁移旧点赞数据”。迁移会：

- 将旧 `likers` 中的微信标识哈希为内部用户 ID；
- 在 `postLikes` 创建唯一点赞记录；
- 按迁移结果修正点赞数；
- 从公开帖子中永久移除 `likers` 字段。

每个云环境只需执行一次。迁移完成后再次点击会显示处理 0 篇帖子。

## 4. 验证

- 登录后进入社区，已有点赞应保持点亮。
- 点赞和取消点赞后，`postLikes` 中同一用户、同一帖子始终只有一条记录。
- `posts` 文档只保留数字字段 `likes`，不再出现 `likers`。
- 未登录用户可以查看点赞数，但点击点赞会先进入登录页。
